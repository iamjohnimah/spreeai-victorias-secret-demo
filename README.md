# Victoria’s Secret · SPREEAI demo
Independent concept based on the first 15 products observed at https://www.victoriassecret.com/us/vs/sale on October 3, 2026. Not an official retailer site or endorsement.

Static storefront with local search, categories, sorting, product galleries, favorites, shopping bag and retailer checkout links. SPREEAI fitting room includes profile/twin selection, supported live try-on, side-by-side comparison (up to three), sizing requests, fit guidance, style edit, outfit building and saved looks. Back and video try-on are marked coming soon.

Live previews use an isolated SPREEAI staging partner. Some lingerie previews were rejected by its image provider and remain unavailable; original retailer photos are shown instead. Fragrance and the multipack are product-only. Size recommendations require calibrated charts and show an unavailable message if no chart exists. Stock, checkout and payment remain with Victoria’s Secret. Photographs and wordmark belong to their owners.

Only static browser assets are published. No admin credentials, server secrets or private source history are included.
